# In html files disable double quotes popping up automatically after typing e.g. `<meta name=` right after `=`

## GUI: In `Settings` go to `HTML: Auto Create Quotes` and disable it

## Config file: In `settings.json` insert the following line
```json
{
  "html.autoCreateQuotes": false,
}
```
